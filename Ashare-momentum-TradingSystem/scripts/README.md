# Scripts

[Cantonese version](README.yue.md)

- `run_factor_research.py`: build factors, IC tables, and quantile portfolios.
- `run_model_comparison.py`: generate embargoed walk-forward predictions.
- `run_portfolio_backtest.py`: simulate the cost-aware top-N portfolio.
- `run_etf_regime_research.py`: generate lagged ETF exposure schedules.
- `generate_report_assets.py`: rebuild publication figures and headline metrics.
- `build_robustness_evidence.py`: calculate HAC factor tests, non-overlapping quantiles, and matched-period benchmarks.
- `build_results_manifest.py`: hash every published result artifact.
