# Source Modules

[Cantonese version](README.yue.md)

- `data.py`: market-table validation, normalization, and point-in-time membership.
- `factors.py`: daily and intraday factor construction plus the low-volatility blend.
- `validation.py`: Rank IC and cross-sectional quantile tests.
- `models.py`: embargoed walk-forward regression utilities.
- `backtest.py`: costs, board lots, minute execution, and portfolio simulation.
- `risk.py`: ETF breadth regimes and lagged exposure schedules.
- `execution.py`: strategy-versus-manual position ownership.
